Open index.html in a browser to preview the website.

To publish:
1. Upload the unzipped folder to a GitHub repository.
2. Import the repository into Vercel.
3. Use the default settings (no build command; output directory is the project root).

Before public launch, verify the phone number, email address, WhatsApp number,
business licensing/regulatory wording and that the contact details are still correct.
